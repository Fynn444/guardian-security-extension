# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for vulnerabilities that could expose
users to risk.

Instead, use GitHub's private vulnerability reporting feature for this
repository once it is enabled under:

**Settings → Security → Private vulnerability reporting**

Include:

- the affected version;
- a clear description of the issue;
- reproduction steps;
- impact;
- any proof-of-concept material needed to reproduce the issue safely.

Please avoid sending real credentials, API keys, browser history, or other
sensitive user data.

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Scope notes

Guardian Security is currently a local-first demonstration extension. Its URL
heuristics can produce false positives and should not be treated as a complete
replacement for a browser's native protections or a commercial secure web
gateway.
