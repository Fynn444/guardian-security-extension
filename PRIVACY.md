# Privacy

Guardian Security 1.0.0 is local-only.

It reads URLs for the sole purpose of evaluating navigation and visible Google
search-result links. This version does not transmit those URLs to a remote
server.

The extension stores the following locally in Chrome extension storage:

- protection settings;
- user allowlist;
- user blocklist;
- temporary five-minute allow decisions;
- aggregate blocked/warning counters.

If a future version integrates a threat-intelligence service, its privacy policy
and user disclosure should be updated before release.
